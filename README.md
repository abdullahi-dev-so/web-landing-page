# HTML & CSS Landing Page

## What It Is

A simple and responsive landing page built with **HTML and CSS**.

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/abdullahi-dev-so/web-landing-page.git
```

### 2. Open the project

```bash
cd web-landing-page
```

### 3. Run the website

Open `index.html` in your web browser.

You can also use **VS Code Live Server** to run the project locally.

## Technologies Used

* HTML5
* CSS3
* script
